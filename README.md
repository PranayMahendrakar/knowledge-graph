# 🕸️ Knowledge Graph Builder

**AI-Powered Visual Learning Tool**

Author: Pranay M

## Overview

Creates visual knowledge graphs from course materials including concept maps, mind maps, timelines, and flowcharts.

## Features

- Entity extraction from text
- Concept map generation
- Mind map creation
- Timeline building
- Flowchart generation
- Study guide creation

## Installation

```bash
ollama pull llama3.2
pip install -r requirements.txt
python main.py
```
